# Junior Rangers Academy

This repository contains a web-based interactive game titled **Junior Rangers Academy**. The entire application is built into a single HTML file (`junior-rangers-academy-v2.html`) which includes all the styles and scripts necessary to run the game.

## Overview

The game provides a themed experience set in a rainforest environment where players can log in as junior rangers, choose avatars, select difficulty levels, and interact through a chat-based mentor system. It features:

- Custom login and user setup screens
- Avatar and difficulty selection
- A mentor chat interface with fun facts about wildlife
- In-game HUD and UI elements styled with CSS variables for a rainforest aesthetic
- Responsive design optimized for desktop browsers

## Getting Started

No build tools or server setup are required to run the game. Simply open the HTML file in any modern web browser.

### Running Locally

1. Clone or download this repository.
2. Open `junior-rangers-academy-v2.html` in your browser (double-click or drag into the browser window).
3. The game should load immediately, and you can start playing.

> **Note:** For the best experience, use a browser with good CSS and JavaScript support (e.g., Chrome, Firefox, Safari, Edge).
